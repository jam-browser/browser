# Jam Browser

**친구와 같은 웹페이지를 함께 보는** Windows 데스크톱 브라우저예요 (Electron).
중앙 서버 없이 호스트 PC에 친구가 직접 접속하고, 모든 대화는 암호화돼요.

## 설치

### ⬇ [Jam Browser 설치 파일 받기 (Windows, 최신 버전)](https://github.com/jam-browser/browser/releases/latest/download/JamBrowser-Setup.exe)

받은 `JamBrowser-Setup.exe` 를 실행하면 묻지 않고 바로 설치돼요 (관리자 권한 불필요, 바탕화면·시작 메뉴 바로가기 생성).
설치된 앱은 새 버전이 나오면 **자동으로 업데이트**돼요. 이전 버전은 [Releases](https://github.com/jam-browser/browser/releases) 에 있어요.

명령어로 받기 (PowerShell):

```powershell
Invoke-WebRequest https://github.com/jam-browser/browser/releases/latest/download/JamBrowser-Setup.exe -OutFile JamBrowser-Setup.exe; .\JamBrowser-Setup.exe
```

> 코드 서명 인증서가 없어서 처음 실행할 때 Windows 가 "PC를 보호했습니다"라고 할 수 있어요. "추가 정보 → 실행"을 누르세요.

## Jam 사용법

1. 오른쪽 패널에서 이름을 입력하고 **Jam 시작하기**
2. 나오는 초대 코드를 **전부** 친구에게 보내기
   - 같은 네트워크: `jam://192.168.x.x:3030/방코드/비밀키`
   - 인터넷(중계 서버): `jamr://중계주소:3031/경로/방코드/비밀키`
3. 친구가 초대 코드를 붙여 넣고 **참여하기** → 호스트 화면의 요청 카드에서 **수락**

처음 Jam을 시작하면 Windows 방화벽 창이 뜰 수 있어요. **개인 네트워크 허용**을 눌러야 같은 네트워크의 친구가 들어올 수 있어요.

## Jam 기능

| 기능 | 설명 |
| --- | --- |
| JAM 탭 | Jam과 연결된 탭. 다른 탭은 나만 보는 개인 탭 |
| 같은 사이트 = 자유 | 같은 사이트 안에서는 누구나 페이지를 넘길 수 있고 모두 함께 이동 |
| 다른 사이트 = 권한 | 다른 사이트로 가는 링크는 잠김(🔒). 호스트가 사람별로 또는 전체에 권한을 줌 |
| 여러 개의 커서 | 같은 페이지를 보는 사람들의 마우스가 이름표와 함께 보임. 창 밖으로 나가면 사라짐 |
| 보고 있는 영역 | 각자 보는 부분이 **색 사각형 + 해상도(예: 1280×720 · 150%)** 로 표시. 미니맵에도 표시 |
| 해상도가 달라도 정확 | 위치를 "페이지 요소 기준"으로 주고받아서 창 크기·확대율이 달라도 같은 내용을 가리킴 |
| 사람 따라가기 | 페이지 위 오버레이에서 사람을 누르면 그 사람이 보는 곳을 계속 따라감 (직접 스크롤하면 멈춤) |
| 동영상 맞추기 | 재생/일시정지/위치를 맞춤. 광고를 보는 사람은 광고가 끝난 뒤 따라옴 (광고를 막거나 건너뛰지 않음) |
| 로그인 | 로그인 창은 각자 자기 것만 보임. 로그인이 끝나면 Jam 화면으로 자동 이동하고 그때부터 따라감 |
| 대기열 · 채팅 · 리액션 | 다른 탭에서 찾은 페이지를 대기열에 추가, 채팅, 이모지 |
| 패널 숨기기 | 패널의 ✕ 또는 Ctrl+J. 숨겨도 오버레이(사람 목록 · 💬)는 남음 |

## 보안

| 항목 | 내용 |
| --- | --- |
| 비밀키 | 초대 코드마다 32바이트 비밀키. 키 자체는 네트워크로 보내지 않고, 서버가 준 일회용 값에 서명해서 증명 |
| 암호화 | 모든 메시지는 AES-256-GCM 암호화 + 위변조 검사. 중계 서버도 내용·이름을 볼 수 없음 |
| 참여 승인 | 기본으로 호스트가 수락해야 입장. 잠깐 끊긴 사람은 5분 안에 승인 없이 복귀 |
| 침입 방어 | 틀린 초대 코드 8번 → 10분 차단(중계로 온 손님도 IP별), 접속 수·메시지 수 제한, 웹페이지에서 서버 접속 차단 |
| 로그인 정보 | 로그인·인증·결제 주소는 공유·기록하지 않음. 쿠키는 각자 PC에만 |
| 다운로드 보관 | exe·msi·bat·ps1·zip 등은 `이름.다운로드확인전` 으로 저장되어 더블클릭해도 실행되지 않음. 다운로드 목록에서 직접 **실행 가능하게 풀기**를 눌러야 원래 이름이 됨. 모든 파일에 "인터넷에서 받은 파일" 표시 |
| Jam이 데려간 다운로드 | Jam 이동 때문에 열린 페이지가 파일을 받으려 하면 막음 |
| 클립보드 경고 | 사이트가 클립보드에 복사하면 내용을 보여주고 **"명령어라면 절대 실행하지 마세요"** 경고 |
| 웹페이지 권한 | 카메라·마이크·위치·알림 등은 모두 거절 |
| 사이트 아이콘 | 외부 아이콘 서비스를 쓰지 않음 (방문 사이트가 제3자에게 전달되지 않음) |
| 소리 | 앱과 모든 웹페이지 음소거 |

## 브라우저 기능 · 꾸미기 (☰ 메뉴 → 설정, Ctrl+,)

- **프리셋**: 기본(위쪽 탭) / 세로 탭 + 페이지 색 / 컴팩트 / 세로 탭
- **모양**: 다크·라이트·시스템 테마, 강조색(직접 선택 또는 페이지 색 따라가기), 컴팩트 모드, 모서리 둥글기
- **배치**: 탭 위치(위·아래·왼쪽·오른쪽), Jam 패널 왼쪽/오른쪽, 오버레이 위/아래, 북마크 바, 홈 버튼, 미니맵
- **새 탭**: 스피드 다이얼 또는 홈페이지 / 검색 엔진(Google·네이버·DuckDuckGo·Bing) / 시작할 때 탭 복원
- **사이트 꾸미기**: 사이트별 CSS로 웹페이지 모양 바꾸기 (나에게만 적용)
- **사용자 CSS**: 브라우저 화면 자체를 CSS로 꾸미기 · 설정 내보내기/가져오기
- **탭**: 고정, 복제, 드래그 정렬, 분할 화면, 우클릭 메뉴, 닫은 탭 다시 열기
- **기타**: 북마크, 방문 기록, 페이지 내 찾기, 사이트별 확대 기억, 전체 화면, 다운로드 목록, 자동 업데이트

단축키: `Ctrl+T/W` 새 탭/닫기 · `Ctrl+Shift+T` 닫은 탭 열기 · `Ctrl+L` 주소창 · `Ctrl+D` 북마크 · `Ctrl+H` 기록 · `Ctrl+F` 찾기 · `Ctrl++/-/0` 확대/축소 · `Ctrl+J` Jam 패널 · `Ctrl+,` 설정 · `F11` 전체 화면

## 멀리 있는 친구와 하기: 중계 서버

저렴한 Windows 서버(또는 집 PC) 하나에 중계 서버를 설치하면 돼요. 중계 서버는 **길만 이어 주고 내용은 볼 수 없어요.**
설치 방법과 자동 업데이트는 [jam-browser/backend](https://github.com/jam-browser/backend) 를 보세요.

| 포트 | 어디서 | 용도 |
| --- | --- | --- |
| TCP 3030 | 호스트 PC | 같은 네트워크 친구의 직접 접속 (공유기 포트 포워딩하면 인터넷에서도 직접 접속 가능) |
| TCP 3031 | 중계 서버 | 인터넷 친구 접속 |

자세한 사용법·보안·포트 안내: [jam-browser/docs](https://github.com/jam-browser/docs)

## 개발

```bash
npm install
node node_modules/electron/install.js   # npm 이 Electron 본체를 받지 않았을 때
npm start          # 실행
npm run jam        # Jam 테스트 환경: 호스트 + 게스트 창 + 로컬 중계 서버
npm test           # 서버 테스트 (+ backend 저장소가 옆 폴더에 있으면 중계 연동 테스트)
npm run dist       # 설치 파일 만들기 (dist/)
```

### Jam 테스트 환경 (`npm run jam`)

한 PC 에서 Jam 을 직접 해 볼 수 있게 앱 두 개와 중계 서버를 함께 띄워요. Ctrl+C 로 전부 종료.

| | |
| --- | --- |
| 창 | `Jam Browser [host]`, `Jam Browser [guest]` — 프로필이 따로라 로그인·설정이 섞이지 않고, `.jam-dev/` 에 남아서 다음에도 유지돼요 |
| 중계 서버 | backend 저장소가 옆 폴더(`../backend`)에 있으면 `127.0.0.1:3031` 로 같이 떠요. 호스트 Jam 패널의 중계 서버 주소에 넣으면 인터넷 방식(`jamr://`)도 시험할 수 있어요 |
| 같은 네트워크 방식 | 호스트가 받은 `jam://…` 초대 코드를 게스트에 그대로 붙여 넣으면 돼요 |

옵션 (`npm run jam -- <옵션>`): `--guests 2` 게스트 여러 명 · `--fresh` 프로필 지우고 새로 · `--no-relay` 중계 서버 없이 · `--debug` 각 창에 CDP 디버그 포트 (비어 있는 포트를 골라서 출력)

E2E 테스트는 [`test/e2e`](test/e2e) 참고. Windows 가 기본 포트를 예약해 둔 PC 에서는 `JAM_E2E_HOST_PORT` · `JAM_E2E_GUEST_PORT` · `JAM_E2E_SITE_PORT` 로 바꿔요.

릴리스: `package.json` 의 버전을 올리고 `npm run dist` 로 만든 설치 파일을 `gh release create v버전 …` 으로 올리면, 설치된 앱들이 자동으로 업데이트해요 (자동 빌드 설정은 [`ci/`](ci)).
릴리스에는 버전 없는 이름의 사본 `JamBrowser-Setup.exe` 도 꼭 함께 올려 주세요 — 위의 "설치 파일 받기" 링크가 항상 최신을 가리키게 돼요.

### 구조

```
src/main.js                Electron 메인 (창, 단축키, 다른 사이트 이동 잠금, 다운로드 보관, 권한 거절, 자동 업데이트)
src/preload.js             앱 화면에 노출하는 API
src/webview-preload.js     웹페이지 안: 커서·영역·스크롤·동영상·클립보드 감시, 다른 사람 커서/사각형, 링크 잠금
src/renderer/app.js        탭 · 주소창 · Jam (암호화 통신, 로그인 대기, 따라가기, 오버레이)
src/renderer/safety.js     클립보드 경고 · 다운로드 목록
src/renderer/customize.js  설정 · 꾸미기 · 북마크 · 기록 · 찾기 · 확대 · 분할 화면 · 스피드 다이얼 · 업데이트 알림
server/jam-server.js       호스트 PC 안에서 도는 Jam 방 서버 (인증·암호화·승인·권한·차단)
server/relay-tunnel.js     호스트 PC ↔ 중계 서버 터널
shared/                    같은 사이트 판단 · 로그인 주소 판별 · 암호화 (Node 쪽)
test/                      서버·중계 테스트, 실제 앱 E2E (test/e2e/README.md)
```

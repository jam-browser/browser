      기본은 중앙 서버 없이 내 PC(호스트)에 친구가 직접 접속하는 방식이에요(같은 와이파이/네트워크). 멀리 있는 친구와 하려면 중계 서버 주소를 넣으세요. 중계 서버는 길만 이어 주고, 대화는 초대 코드의 비밀키로 암호화되어 있어서 중계 서버도 내용을 볼 수 없어요.

      한 줄에 하나씩 여러 개 넣을 수 있어요. 위에서부터 연결되는 첫 주소를 써요 (예: 집 안 주소 → 외부 IP → DDNS 이름).

            계정 비밀번호 바꾸기
            
            
            
            
          
                        
          
                        
            
            
          
                        
          
                        
            어떻게 보호되나요?
            
                          
              
                        • 계정 비밀번호 + 계정마다 다른 무작위 솔트 + 이 PC 의 비밀 키로 scrypt(일부러 느린 해시)를 돌려 열쇠를 만들어요. 비밀번호 자체는 어디에도 저장하지 않아요.
                          • 
              
                        • 그 열쇠로 데이터 열쇠를 풀고, 데이터는 AES-256-GCM 과 ChaCha20(+HMAC-SHA256) 두 가지 서로 다른 암호로 이중 암호화해요. 사이트 비밀번호 하나하나도 따로 한 번 더 이중 암호화돼요.
                          • 
              
                        • 그 위에 Windows 계정 암호화(DPAPI)를 한 겹 더 씌워 다른 Windows 사용자나 복사된 파일로는 열 수 없어요.
                          • 
              
                        • 비밀번호를 여러 번 틀리면 다음 시도까지 기다려야 해요. 비밀번호 "보기"는 계정 비밀번호를 다시 물어봐요.
                          • 
              
                        • Jam 서버(내 PC · 중계 서버)는 길만 이어 줘요. 저장한 비밀번호·친구 목록은 이 PC 밖으로 나가지 않아요. 친구 확인은 서명만 보내요.
